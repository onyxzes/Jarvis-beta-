# Jarvis

Asistente personal para Android. Fase 1: la app con sus tres pantallas (Inicio, Bóveda y Control) y voz de hombre.

## Cómo descargar el APK
1. Entrá a la pestaña **Actions** de este repo.
2. Abrí la última ejecución **Build APK** (la de arriba, con el tilde verde).
3. Abajo de todo, en **Artifacts**, tocá **Jarvis-APK** para bajar el instalador.
4. Descomprimí el .zip, y en el celular instalá `app-debug.apk` (permití "orígenes desconocidos").
